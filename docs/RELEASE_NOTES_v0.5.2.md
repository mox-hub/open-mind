OpenMind v0.5.2 —— 首个对外发布版本（Windows x64）

本地优先的开源思维导图桌面工具。完全免费、无账号、无遥测，文件以 `.omd` 保存在本地。

## 安装

- **安装包**：`OpenMind_0.5.2_x64-setup.exe`（NSIS）
- **免安装绿色版**：`open-mind.exe`，双击即用

系统要求：Windows 10/11 x64 + WebView2（Win11 自带）。

> 未购买代码签名证书，首次运行 Windows SmartScreen 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」即可。这是开源项目常见现象，无安全问题。

## 本版内容

- 核心编辑：增删改 / 拖拽 / 折叠 / 撤销重做 / 方向键导航 / 多选 / 节点上移下移 / 复制剪切粘贴
- 右键菜单：插入各级节点、图标、标签、备注、链接、图片、概要、关联线、外框、展开控制、清除样式；画布菜单（展开/收起全部、重置布局、适应画布、全屏、删除关联线、查找、全选）
- 节点样式面板：文字/背景/边框颜色与粗细、字号、加粗斜体、9 种形状
- 8 种结构：逻辑图（右/左）、思维导图（左右）、组织架构图、目录组织图、时间轴（横向/竖向）、鱼骨图
- 7 个主题（含 2 个暗色）+ 彩虹分支配色
- 多画布：一个 `.omd` 文件支持多张画布，底部标签页切换
- 模板库：10 个内置模板
- 大纲视图、查找替换、演示模式、小地图
- 导入 Markdown / OPML / FreeMind / XMind / TXT；导出 PNG / SVG / PDF / Markdown / OPML / TXT / XMind / FreeMind
- `.omd` 原子写自动保存、会话恢复、未保存关闭自动备份
